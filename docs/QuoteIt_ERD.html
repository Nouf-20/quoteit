Relationship (1 : N)
UQ = unique constraint
Relationships: one user publishes many quotes (1:N)  ·  one quote receives many likes (1:N)  ·  one user gives many likes (1:N).   Users and quotes therefore form a many-to-many relationship through quote_likes. Foreign keys use cascade delete, so deleting a user or a quote removes the related likes automatically.
Framework support tables: Laravel also creates sessions, cache, cache_locks, jobs, and related infrastructure tables; they are omitted here because they do not represent project domain entities.
